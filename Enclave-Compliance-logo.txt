Production Note for Code Integration

When embedding the SVG directly into your React / Next.js header components, wrap the icon in a flex container with items-center to guarantee pixel-perfect alignment across different render engines:

JavaScript
<div className="flex items-center gap-2">
  <svg className="h-10 w-auto" viewBox="0 0 540 80">
    {/* Integrated SVG Paths */}
  </svg>
</div>
